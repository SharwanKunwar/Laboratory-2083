### Q2. Write a JS program to highlight all words over eight characters long in the paragraph text (with a red background).

```html
<!DOCTYPE html>
<html>
<body>
  <p id="para">JavaScript is a powerful programming language used for creating interactive websites and applications.</p>

  <script>
    let para = document.getElementById("para");
    let words = para.innerText.split(" ");

    let result = words.map(word => {
      if (word.length > 8) {
        return `<span style="background-color:red; color:white;">${word}</span>`;
      }
      return word;
    });

    para.innerHTML = result.join(" ");
  </script>
</body>
</html>
```
**Explanation:** The paragraph text is split into words, each word's length is checked, and words longer than 8 characters are wrapped in a `<span>` with a red background using inline CSS, then the paragraph's HTML is updated.

### Q3. What is JavaScript? Explain different types of JavaScript with proper example. [1+4]

**JavaScript** is a lightweight, interpreted, client-side scripting language used to make web pages interactive and dynamic. It can also run on the server side (e.g., Node.js).

**Types of JavaScript (based on placement):**

| Type | Description | Example |
|---|---|---|
| **Inline JavaScript** | Written directly inside an HTML tag using an event attribute | `<button onclick="alert('Hi')">Click</button>` |
| **Internal (Embedded) JavaScript** | Written within `<script>` tags inside the HTML document | `<script>alert('Hello');</script>` |
| **External JavaScript** | Written in a separate `.js` file and linked to HTML | `<script src="script.js"></script>` |

**Example (External):**
```html
<script src="app.js"></script>
```
```javascript
// app.js
console.log("External JS loaded");
```

External JS is preferred for larger projects since it improves reusability, caching, and separation of concerns (HTML vs logic).

### Q4. Write a PHP function that accepts username and password as arguments and checks with student table; if credentials match, redirect to dashboard page, otherwise display 'Invalid username/password'. [5]

```php
<?php
function checkLogin($username, $password) {
    $conn = new mysqli("localhost", "root", "", "college_db");

    if ($conn->connect_error) {
        die("Connection failed: " . $conn->connect_error);
    }

    $username = $conn->real_escape_string($username);
    $password = $conn->real_escape_string($password);

    $sql = "SELECT * FROM student WHERE username='$username' AND password='$password'";
    $result = $conn->query($sql);

    if ($result->num_rows > 0) {
        header("Location: dashboard.php");
        exit();
    } else {
        echo "Invalid username/password";
    }

    $conn->close();
}

// Example call
checkLogin($_POST['username'], $_POST['password']);
?>
```
**Note:** In production, passwords should be hashed (`password_hash`/`password_verify`) and queries should use prepared statements to prevent SQL injection.

### Q5. What is jQuery? Explain XMLHttpRequest object with its properties and methods with relevant example. [1+4]

**jQuery** is a fast, lightweight JavaScript library that simplifies HTML DOM manipulation, event handling, animation, and AJAX interactions using simple syntax (`$()`).

**XMLHttpRequest (XHR):** A built-in JavaScript object used to exchange data with a server asynchronously (AJAX) without reloading the page.

**Key Properties:**
| Property | Description |
|---|---|
| `readyState` | Current state of the request (0–4) |
| `status` | HTTP status code (e.g., 200, 404) |
| `responseText` | Response data as text |
| `onreadystatechange` | Event handler triggered on state change |

**Key Methods:**
| Method | Description |
|---|---|
| `open(method, url, async)` | Initializes the request |
| `send()` | Sends the request to the server |
| `setRequestHeader()` | Sets an HTTP header |
| `abort()` | Cancels the request |

**Example:**
```javascript
let xhr = new XMLHttpRequest();
xhr.open("GET", "data.txt", true);
xhr.onreadystatechange = function() {
    if (xhr.readyState === 4 && xhr.status === 200) {
        document.getElementById("output").innerHTML = xhr.responseText;
    }
};
xhr.send();
```

### Q7. Write rules to create a variable in PHP. How to create, store, access and destroy session in PHP? [1+4]

**Rules to create a PHP variable:**
- Must start with a `$` sign, followed by a letter or underscore.
- Cannot start with a number.
- Can contain only alphanumeric characters and underscores (`A-z`, `0-9`, `_`).
- Are case-sensitive (`$Name` and `$name` are different).
- No spaces or special characters (`-`, `%`, etc.) allowed.

**Session Handling in PHP:**

**1. Create/Start a session:**
```php
<?php
session_start();
?>
```

**2. Store data in session:**
```php
<?php
$_SESSION['username'] = "Mahakal";
$_SESSION['id'] = 101;
?>
```

**3. Access session data:**
```php
<?php
session_start();
echo $_SESSION['username'];
?>
```

**4. Destroy session:**
```php
<?php
session_start();
session_unset();     // removes all session variables
session_destroy();   // destroys the session
?>
```

**a) Types of Array in PHP**

| Type | Description | Example |
|---|---|---|
| **Indexed Array** | Array with numeric index | `$arr = array("A","B","C");` |
| **Associative Array** | Array with named (string) keys | `$arr = array("name"=>"Ram","age"=>20);` |
| **Multidimensional Array** | Array containing one or more arrays | `$arr = array(array(1,2),array(3,4));` |

**b) Arrow Function in JavaScript**

An arrow function (`=>`) is a shorter syntax for writing function expressions, introduced in ES6. It does not have its own `this` binding.

```javascript
// Traditional function
function add(a, b) {
    return a + b;
}

// Arrow function
const add = (a, b) => a + b;

console.log(add(5, 3)); // 8
```

**c) jQuery UI**

jQuery UI is a library built on top of jQuery that provides ready-made GUI widgets (datepicker, slider, dialog, accordion, tabs), interactions (drag, drop, resize), effects, and theming to build interactive web interfaces quickly.

```javascript
$(function() {
    $("#datepicker").datepicker();
});
```

### Q9. Write server-side script to create and validate a form with given rules and store data into 'patients' table. [3+4+3]

**Validation Rules:**
- Name, Mobile, Doctor Name, Gender, DOB → Required
- Mobile → 10 digits, starts with 98, 97, or 96
- DOB → YYYY-MM-DD format

**HTML Form (patient_form.html):**
```html
<!DOCTYPE html>
<html>
<body>
<form action="save_patient.php" method="POST">
    Name: <input type="text" name="name"><br>
    Patient ID: <input type="text" name="patient_id"><br>
    Mobile: <input type="text" name="mobile"><br>
    Gender:
    <select name="gender">
        <option value="Male">Male</option>
        <option value="Female">Female</option>
        <option value="Other">Other</option>
    </select><br>
    Address: <input type="text" name="address"><br>
    DOB (YYYY-MM-DD): <input type="text" name="dob"><br>
    Doctor Name: <input type="text" name="doctor_name"><br>
    <input type="submit" value="Submit">
</form>
</body>
</html>
```

**PHP Validation Script (save_patient.php):**
```php
<?php
$errors = [];

$name        = $_POST['name'] ?? '';
$patient_id  = $_POST['patient_id'] ?? '';
$mobile      = $_POST['mobile'] ?? '';
$gender      = $_POST['gender'] ?? '';
$address     = $_POST['address'] ?? '';
$dob         = $_POST['dob'] ?? '';
$doctor_name = $_POST['doctor_name'] ?? '';

// Required field validation
if (empty($name))        $errors[] = "Name is required.";
if (empty($mobile))      $errors[] = "Mobile is required.";
if (empty($doctor_name)) $errors[] = "Doctor name is required.";
if (empty($gender))      $errors[] = "Gender is required.";
if (empty($dob))         $errors[] = "DOB is required.";

// Mobile validation: 10 digits, starts with 98/97/96
if (!empty($mobile) && !preg_match('/^(98|97|96)[0-9]{8}$/', $mobile)) {
    $errors[] = "Mobile must be 10 digits and start with 98, 97 or 96.";
}

// DOB format validation: YYYY-MM-DD
if (!empty($dob) && !preg_match('/^\d{4}-\d{2}-\d{2}$/', $dob)) {
    $errors[] = "DOB must be in YYYY-MM-DD format.";
}

if (!empty($errors)) {
    foreach ($errors as $e) {
        echo $e . "<br>";
    }
    exit();
}

// Database Insertion
$conn = new mysqli("localhost", "root", "", "hospital_db");
if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
}

$stmt = $conn->prepare("INSERT INTO patients (name, patient_id, mobile, gender, address, dob, doctor_name) VALUES (?, ?, ?, ?, ?, ?, ?)");
$stmt->bind_param("sssssss", $name, $patient_id, $mobile, $gender, $address, $dob, $doctor_name);

if ($stmt->execute()) {
    echo "Patient record saved successfully.";
} else {
    echo "Error: " . $stmt->error;
}

$stmt->close();
$conn->close();
?>
```

**Summary:** The form collects patient details, PHP validates required fields, mobile number pattern, and DOB format using regular expressions, and on successful validation, a prepared statement safely inserts the data into the `patients` table — preventing SQL injection.

### Q10. What is JavaScript Event? Explain different methods available to access DOM elements using id, class, name and selector with suitable examples. [2+8]

**JavaScript Event:** An event is an action or occurrence detected by JavaScript that happens in the browser — such as a mouse click, key press, page load, or form submission — which can trigger a function (event handler) to run in response. Examples: `onclick`, `onchange`, `onmouseover`, `onload`.

```javascript
document.getElementById("btn").onclick = function() {
    alert("Button clicked!");
};
```

**Methods to Access DOM Elements:**

**1. By ID — `getElementById()`**
Returns a single element with the matching `id`.
```html
<p id="msg">Hello</p>
<script>
    let el = document.getElementById("msg");
    el.style.color = "blue";
</script>
```

**2. By Class — `getElementsByClassName()`**
Returns an HTMLCollection of all elements with the given class name.
```html
<p class="note">One</p>
<p class="note">Two</p>
<script>
    let items = document.getElementsByClassName("note");
    for (let i = 0; i < items.length; i++) {
        items[i].style.backgroundColor = "yellow";
    }
</script>
```

**3. By Name — `getElementsByName()`**
Returns a NodeList of elements sharing the same `name` attribute (commonly used with form fields).
```html
<input type="radio" name="gender" value="M">
<input type="radio" name="gender" value="F">
<script>
    let genderInputs = document.getElementsByName("gender");
    console.log(genderInputs.length); // 2
</script>
```

**4. By Selector — `querySelector()` and `querySelectorAll()`**
Uses CSS-style selectors; `querySelector()` returns the first match, `querySelectorAll()` returns all matches.
```html
<div class="box" id="first">A</div>
<div class="box">B</div>
<script>
    let single = document.querySelector("#first");      // by id
    let all = document.querySelectorAll(".box");         // all elements with class box

    single.style.border = "1px solid red";
    all.forEach(box => box.style.margin = "5px");
</script>
```

**Comparison Table:**

| Method | Access By | Returns |
|---|---|---|
| `getElementById()` | id | Single Element |
| `getElementsByClassName()` | class | HTMLCollection (live) |
| `getElementsByName()` | name | NodeList |
| `querySelector()` | CSS selector | First matching Element |
| `querySelectorAll()` | CSS selector | NodeList of all matches |

`querySelector`/`querySelectorAll` are the most flexible since they accept any valid CSS selector (id, class, tag, attribute, or combinations).

### Q11. What is Inheritance? Explain different ways to implement polymorphism in PHP with proper example. [2+8]

**Inheritance:** Inheritance is an object-oriented programming concept where a child (derived) class acquires the properties and methods of a parent (base) class using the `extends` keyword, enabling code reuse and hierarchical class relationships.

```php
<?php
class Animal {
    public function sound() {
        echo "Animal makes a sound\n";
    }
}

class Dog extends Animal {
    public function bark() {
        echo "Dog barks\n";
    }
}

$d = new Dog();
$d->sound(); // inherited
$d->bark();
?>
```

**Polymorphism in PHP:** Polymorphism means "many forms" — the ability of different classes/objects to respond to the same method call in different ways. PHP implements polymorphism mainly through **method overriding** (since PHP does not support traditional method overloading) and **interfaces**.

**1. Polymorphism via Method Overriding**
A child class redefines a method already defined in its parent class.
```php
<?php
class Shape {
    public function area() {
        echo "Area not defined\n";
    }
}

class Circle extends Shape {
    public $radius;
    public function __construct($radius) {
        $this->radius = $radius;
    }
    public function area() {
        echo "Area of Circle: " . (3.14 * $this->radius * $this->radius) . "\n";
    }
}

class Square extends Shape {
    public $side;
    public function __construct($side) {
        $this->side = $side;
    }
    public function area() {
        echo "Area of Square: " . ($this->side * $this->side) . "\n";
    }
}

$shapes = [new Circle(5), new Square(4)];
foreach ($shapes as $shape) {
    $shape->area(); // same method call, different behavior
}
?>
```

**2. Polymorphism via Interfaces**
Different classes implement the same interface but define the method differently.
```php
<?php
interface Payment {
    public function pay($amount);
}

class CreditCard implements Payment {
    public function pay($amount) {
        echo "Paid $amount using Credit Card\n";
    }
}

class Paypal implements Payment {
    public function pay($amount) {
        echo "Paid $amount using PayPal\n";
    }
}

function processPayment(Payment $method, $amount) {
    $method->pay($amount);
}

processPayment(new CreditCard(), 500);
processPayment(new Paypal(), 800);
?>
```

**3. Polymorphism via Abstract Classes**
An abstract class defines a method signature that all child classes must implement in their own way.
```php
<?php
abstract class Employee {
    abstract public function calculateSalary();
}

class Manager extends Employee {
    public function calculateSalary() {
        echo "Manager salary: 80000\n";
    }
}

class Developer extends Employee {
    public function calculateSalary() {
        echo "Developer salary: 60000\n";
    }
}
?>
```

**Summary:** In each approach, the same method name (`area()`, `pay()`, `calculateSalary()`) behaves differently depending on the object calling it — this is the core idea of polymorphism, and it works hand-in-hand with inheritance and interfaces in PHP.
